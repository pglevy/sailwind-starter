# App Spec Example Template

Copy this `_template/` directory to create a new app spec eval example:

```bash
cp -r evals/app-spec/_template evals/app-spec/my-example-name
```

Then populate:

1. **spec.md** — The app spec or PRD describing what to build
2. **expected-structure.json** — Expected pages, components, and data entities
3. **assets/** — Any reference images mentioned in the spec (optional)
